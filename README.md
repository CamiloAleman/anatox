# ANATOX · Descifrando el cuerpo humano

Sitio educativo estático sobre anatomía, embriología, biología molecular y atención al paciente.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
npm run preview
```

Vite genera el sitio de producción en `dist/`. El repositorio está preparado para importarse directamente en Vercel.

## Videos

Los videos se reproducen desde YouTube mediante `youtube-nocookie.com`. El iframe se crea únicamente cuando el visitante abre un video, por lo que YouTube no se carga durante la vista inicial.
